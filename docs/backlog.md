Механизм: «тишина после рукопожатия» — TCP/TLS проходят, но ответы приложения (любой размер, даже favicon) не доходят; мгновенные крошечные ответы края (308-редирект) успевают проскочить. Причина попадания домена в тормоз-список неизвестна (проверка реестра РКН из РФ не прошла — сам rublacklist недоступен). **Решения:** (1) паллиатив — RU-аудитории давать адрес `coach-platform-pi.vercel.app` (работает сейчас, бесплатно, но уродливый URL и вреден для SEO); (2) стратегия — перенос хостинга в РФ (№9): свой IP внутри страны, у ТСПУ нет повода тормозить + снимает 152-ФЗ; промежуточный вариант — второй свежий домен (.ru), привязанный к Vercel (новое имя не в списках торможения) — дешёвый фикс доступности без переезда. **В работе (2026-09-04):** куплен **myrightway.ru** (reg.ru, покупка дооформляется); Vercel-домены добавлены (ждут DNS: A @ → 216.198.79.1, CNAME www → bb922beb65053df0.vercel-dns-017.com). **Итог 2026-09-04 вечер — второй домен НЕ помог:** myrightway.ru полностью настроен (DNS ✅, SSL ✅, www отдаёт HTTP 200 с заголовком «RightWay — Правильный путь»), но из РФ без VPN не открывается. Решающий эксперимент (разделение SNI и IP): SNI `vercel.app` на рабочих IP Vercel → ответ мгновенный (200/403); SNI `www.myrightway.ru` на **тех же самых** рабочих IP → зависание намертво. Значит, ТСПУ фильтрует по **имени домена в TLS-рукопожатии**, а не по IP, и новый .ru-домен попал под фильтр в день регистрации. **Главная гипотеза:** домен в статусе UNVERIFIED (владелец не идентифицирован через Госуслуги, новый закон с 01.09.2026) — неидентифицированные домены ограничиваются на границе. **Следующий шаг: пройти идентификацию через Госуслуги в reg.ru** (плашка «Не идентифицированы данные администратора» на https://www.reg.ru/user/account/services) и перепроверить через 1–2 дня.
