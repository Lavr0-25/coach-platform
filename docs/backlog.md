## 📋 Текущий бэклог (по убыванию рекомендованного приоритета)

| # | Задача | Приоритет | Почему | Объём |
|---|---|---|---|---|
| 1 | **Защита комментариев скрытого урока** | 🔴 Высокий | Дыра безопасности из фичи «Скрытые уроки»: RLS `comments` не проверяет видимость урока — знающий id читает комментарии недоступного ему урока. Правка маленькая (RLS-политика + миграция + спека), а закрывает реальную брешь | Малый |

Техническая часть готова (API, план тем, расписание публикации), но без агента с промптами фича не работает целиком. Строить на ней следующее (cron-робот) бессмысленно, пока нет базовой части | Средний (вне репо) |
| 3 | **Чистка тестовых данных прод-БД** | 🟡 Средний | Тест-мусор на проде: урок b963385e в скрытом режиме, допуски coach2/mentor/tester4-8, аккаунты без профиля (tester4-8, Admin API). Мелкая работа, но делается ДО наполнения реальным контентом, чтобы не чистить вокруг живых пользователей | Малый |
| 4 | **Сайт не работает в РФ без VPN** (наблюдение Анатолия, 2026-09-04) | 🔴 Высокий | **Диагноз установлен окончательно (2026-09-04):** тормозится именно **доменное имя rightway.su**. Доказательства: (а) `coach-platform-pi.vercel.app` — тот же проект на тех же серверах Vercel — из РФ-сети Анатолия открывается за 1,2 с (проверено агентом из его сети); (б) другие сайты Vercel и Supabase из РФ работают; (в) сайт жив из США/Германии/Швеции/Финляндии/Казахстана и серверной точки РФ (ru2); (г) в HTTPS сеть видит только имя сайта в TLS-рукопожатии (SNI) — тормоз срабатывает ровно при SNI rightway.su/www.rightway.su, а при SNI vercel.app контент проходит. Механизм: «тишина после рукопожатия» — TCP/TLS проходят, но ответы приложения (любой размер, даже favicon) не доходят; мгновенные крошечные ответы края (308-редирект) успевают проскочить. Гипотезы про YouTube и Supabase опровергнуты. Причина попадания домена в тормоз-список неизвестна (проверка реестра РКН из РФ не прошла — сам rublacklist недоступен). **Решения:** (1) паллиатив — RU-аудитории давать адрес `coach-platform-pi.vercel.app` (работает сейчас, бесплатно, но уродливый URL и вреден для SEO); (2) стратегия — перенос хостинга в РФ (№9): свой IP внутри страны, у ТСПУ нет повода тормозить + снимает 152-ФЗ; промежуточный вариант — второй свежий домен (.ru), привязанный к Vercel (новое имя не в списках торможения) — дешёвый фикс доступности без переезда | Диагностика: ✅; паллиатив: vercel.app; фикс: №9 или второй домен |
| 5 | **Техписатель: пользовательские инструкции** (идея Анатолия, 2026-09-04) | 🟡 Средний | Скилл/субагент «технический писатель»: после каждой правки логики/интерфейса обновляет пользовательские инструкции.
