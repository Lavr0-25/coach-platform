### Кошелёк ментора + security + фича Б/Б+ (выпущено 18.09)

**ПОЛНЫЙ E2E ПРОЙДЕН (18.09 утро), 3 бага найдено и исправлено:**

1. **Роялти всегда 0 ₽** (критический): `payout.ts` и `admin-payout.ts`
   фильтровали lessons/courses по `coach_user_id` — колонки нет. Двойная
   ловушка: колонка называется `coach_id` И ссылается на `coaches.id`
   (профиль), а не на auth user id → сначала `select id from coaches where
   user_id = ...`, потом `.eq('coach_id', coachRow.id)`.
2. **Ложная сверка в /admin/payouts**: `getCoachAvailable` вычитал саму
   обрабатываемую заявку → «Доступно у автора: 700 ₽ — меньше суммы заявки!»
   для нормальной заявки. Добавлен параметр `excludeRequestId`.
3. **Снятая ставка = 0%**: `Number(null) === 0` в `lib/commission.ts` — после
   «снять индивидуальную ставку» (NULL) кабинет показывал «комиссия 0%,
   остаётся 100%» вместо глобальной 30%. NULL проверяется явно.
