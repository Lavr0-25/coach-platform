# Инструкция для ИИ-агента: автопубликация статей автора в Telegram

> Для агента, работающего на компьютере автора (пример: Claude Code).
> Актуально на 2026-09-14. Платформа: «Верный путь» — https://www.myrightway.ru

## Что это даёт

Агент автора ставит посты в **очередь платформы**, а публикует их сервер
платформы — по расписанию. Компьютер автора может быть выключен, VPN не нужен.

## Что работает сейчас (честный статус)

- 🚧 **Постановка постов в очередь** — пока доступна **только администраторам
  платформы** (ключам с ролью `admin`). Пост уходит в общий канал платформы
  без ручной модерации, поэтому открытый доступ всем авторам закрыт до
  появления модерации. Если API отвечает `403` — ваш ключ не админский:
  обратитесь к владельцу платформы.
- ❌ **Свой канал автора** — в разработке (нужна доработка платформы:
  поле «мой канал» в профиле автора + модерация).
- ❌ **Дзен** — платформа пока не поддерживает. Вариант на будущее:
  Дзен умеет импортировать материалы из RSS-ленты — когда у платформы
  появится RSS, Дзен можно подключить без агента. Пока — публикации в
  Дзен вручную или отдельным скриптом агента (см. «Если нужен Дзен уже
  сейчас»).

## Пререквизиты (один раз)

1. **Аккаунт автора на платформе.** Регистрация: https://www.myrightway.ru/register
2. **Ключ агента.** Автор заходит в кабинет → раздел
   **«Управление с ИИ» → «API-ключи агента»** → «Создать ключ».
   Ключ показывается один раз — сохранить в конфиг агента (не коммитить
   в репозиторий, не пересылать в открытом виде).
3. Согласовать с владельцем платформы тему и частоту постов
   (лимит: **5 постов в сутки** на автора).

## API

База: `https://www.myrightway.ru/api/agent`
Авторизация: заголовок `x-agent-key: <ключ автора>`

### Поставить пост в очередь (пока только админские ключи)

⚠️ С 14.09 постановка в очередь разрешена только ключам администраторов
платформы. Обычным ключам сервер отвечает `403` — см. «Что работает сейчас».

```bash
curl -s -X POST https://www.myrightway.ru/api/agent/scheduled-posts \
  -H "Content-Type: application/json" \
  -H "x-agent-key: КЛЮЧ" \
  -d '{
    "text": "Текст поста. До 4096 символов без фото, до 1024 — с фото.",
    "publish_at": "2026-09-15T10:00:00+03:00"
  }'
```

- `publish_at` — строго **в будущем**, ISO-формат с таймзоной.
  Немедленная публикация = поставьте время на 2–3 минуты вперёд
  (очередь разбирается каждые 15 минут).
- С фото: добавьте `"photo_base64": "<base64 картинки>", "photo_ext": "jpg|jpeg|png|webp"`
  (до 5 МБ). С фото текст — до **1024** символов.

Ответ `201`: `{"ok": true, "post": {"id": "...", "status": "pending", ...}}`
— сохраните `id` (пригодится для отмены).

### Посмотреть свои посты

```bash
curl -s "https://www.myrightway.ru/api/agent/scheduled-posts" -H "x-agent-key: КЛЮЧ"
```

Статусы: `pending` (ждёт) → `published` (опубликован; есть `published_at`)
/ `failed` (3 неудачные попытки, причина в `error`) / `cancelled` (отменён).

### Отменить ещё не опубликованный пост

```bash
curl -s -X PATCH https://www.myrightway.ru/api/agent/scheduled-posts \
  -H "Content-Type: application/json" -H "x-agent-key: КЛЮЧ" \
  -d '{"id": "ID-ПОСТА", "cancel": true}'
```

Опубликованные посты не отменяются.

## Правила (сервер отклонит пост, если нарушены)

- Текст не пустой; без фото до 4096 символов, с фото до 1024.
- Нет запрещённых слов (фильтр платформы — стоп-лист уроков).
- Не больше 5 постов в сутки (счёт по календарному дню автора).
- Фото: jpg/jpeg/png/webp, до 5 МБ.

При ошибке `422` сервер возвращает причину по-русски — исправьте текст
и повторите запрос. При `429` — дневной лимит исчерпан, продолжите завтра.

## Режим работы агента (рекомендация)

1. По расписанию (утром) выбрать тему дня и написать пост: живой язык,
   без канцелярита, первая строка цепляет (в превью Telegram видно её).
2. Поставить в очередь с `publish_at` на завтра в выбранное время.
3. На следующий день проверить статус через GET; при `failed` —
   прочитать `error`, исправить и поставить пост заново.
4. Раз в неделю — сводка автору: сколько постов ушло, какие темы.

## Если нужен Дзен уже сейчас

Платформа пока не публикует в Дзен. Варианты до появления поддержки:
- Публиковать в Дзен **вручную** (статья — это не пост: заголовок + длинный
  текст; очередь платформы сейчас заточена под короткие посты).
- Дзен умеет **импортировать RSS-ленту**: когда на платформе появится RSS
  (в планах), Дзен можно будет настроить на автозабор — агенту тогда
  ничего делать не придётся.

## Безопасность

- Ключ = пароль агента. Хранить в конфиге агента с правами только для
  чтения, не пересылать открытым текстом, при утечке — отозвать в кабинете.
- Агент действует от имени автора: за содержимое постов отвечает автор.
- Секреты (ключ, токены) не публиковать в репозиториях и чатах.
