## Что это

Одна публичная страница без авторизации (`app/survey/`) + таблица ответов в Supabase
(`survey_responses`). Вопросы захардкожены в `app/survey/questions.ts` (13 вопросов,
типы: короткий текст / выбор одного / выбор нескольких / шкала 1–5 / длинный текст).

- Форма: `app/survey/SurveyForm.tsx` ('use client'), валидация обязательных на клиенте,
  успешная отправка заменяет форму благодарностью.
- Приём: server action `submitSurvey` в `app/survey/actions.ts`.
- Результаты: `app/admin/survey/page.tsx` (гвард /admin из layout), «Выгрузить JSON» —
  `app/admin/survey/ExportButton.tsx` (правило feedback-json-export-pattern).
- Миграция: `docs/migrations/2026-09-11-survey.sql` (применена 2026-09-11).

## Модель данных

`survey_responses` — одна строка = один респондент:

| поле        | тип      | описание                                                        |
| ----------- | -------- | --------------------------------------------------------------- |
| id          | uuid pk  | генерируется в БД                                               |
| created_at  | timestamptz | момент отправки                                              |
| answers     | jsonb    | все 13 ответов, ключи `q0…q12` (структура — `questions.ts`)      |
| ip_hash     | text     | sha256(ip + соль), обрезан до 32 симв. — для анти-спама и дедупликации |
| user_agent  | text     | до 300 симв., только для отсева ботов при анализе               |

RLS: клиентская INSERT-политика **не даётся** (как `audit_log` / `paid_subscriptions`) —
запись только через сервисный ключ из server action. SELECT — только админ
(каноническая проверка `coaches.role = 'admin'`). Аноним не читает ничего.

## Поток ответа

1. Респондент заполняет форму → `submitSurvey({ answers, honeypot })`.
2. Honeypot (скрытое поле `company_website`) заполнено → тихий `{ ok: true }`, записи нет.
3. Whitelist-валидация: каждый ответ проверяется по `questions.ts` (варианты exact match,
   текст ≤ 2000 симв., шкала — целое 1–5). Обязательные вопросы без ответа → ошибка.
4. Rate limit: не больше 3 отправок с одного `ip_hash` за 5 минут.
5. Вставка через `createAdminClient()`; IP не хранится — только sha256 с солью.

## Ограничения и приватность

- Анонимно: авторизации нет, имя/почту не спрашиваем, сырой IP не храним (152-ФЗ).
- Анти-спам достаточен для разового опроса (~10–20 респондентов); капчи нет.
- Результаты не публичны: читает только админ через /admin/survey.
- `SURVEY_SALT` — env-переменная (`.env.local` + Vercel). Если не задана, работает
  дефолт — хэши всё равно не персданные, но сменить соль после сбора нельзя (сломает
  дедупликацию по ip_hash).
