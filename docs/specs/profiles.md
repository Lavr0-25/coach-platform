# Спека: Публичные профили пользователей (`/profile/[id]`)

> Статус: `stable` · обновлено 2026-09-05 · ответственный: Анатолий + Claude Code

## Задача

У каждого пользователя платформы есть публичная страница профиля: кто он и что прошёл. Раньше страница была только у авторов (`/mentor/[id]`), у студентов не было ничего — в админке на них некуда было кликнуть.

## Поведение

- `/profile/[id]` открывает профиль любого пользователя: аватар (или заглушка-инициалы), имя (или «Студент»), статус «Студент платформы», дата регистрации.
- Блоки: «Пройденные курсы» (карточки курсов), «Купленные уроки» (карточки уроков). Если ни того, ни другого нет — пустое состояние с пояснением.
- Если пользователь — наставник (есть запись в `coaches`), `/profile/[id]` редиректит на его основной профиль `/mentor/<id>`: два экрана одного человека не плодим.
- Несуществующий id → 404.

## Данные и безопасность

- Таблицы: `profiles` (имя, аватар, дата регистрации), `purchases` (что куплено) + `courses`/`lessons` (названия, обложки, цены).
- purchases читаются **сервисным клиентом на сервере** (server component): RLS разрешает клиенту читать только свои покупки, а публичная страница должна показывать их любому посетителю. Наружу отдаётся только минимум: название, обложка, цена — без сумм, статусов платежей и прогресса уроков.
- Старые ссылки `/profile/[id]` больше не редиректят наставника слепо: сперва резолвим автора, затем показываем соответствующую страницу.

## Приватность профиля

- В настройках профиля (кабинет → Профиль → Настройки) есть переключатель «Открытый профиль» (по умолчанию включён).
- Когда он выключен, `/profile/<id>` для всех, кроме владельца и админа, показывает заглушку «Профиль скрыт».
- Владелец всегда видит свой профиль целиком; админ видит и скрытые профили.
- Переключатель сохраняется вместе с профилем (кнопка «Сохранить изменения»).

## Кнопка «Написать сообщение»

- На публичной странице профиля авторизованному зрителю (кроме самого владельца) показывается кнопка «Написать сообщение» — ведёт в чат `/messages/<id>` с этим пользователем.
