# Спека: Справочник «Как здесь работать» (`/help`)

> Статус: `stable` · обновлено 2026-09-04 · ответственный: Анатолий + Claude Code

## Задача

Пользователь в любой момент может узнать, как устроена текущая страница и что на ней
можно сделать. Тексты пишутся заранее (не живой ИИ-ответ) и обновляются «техписателем»
(агентом) после каждой правки интерфейса.

## Замысел (согласовано с Анатолием, 2026-09-04)

- **Не кнопка, а иконка** в подвале каждой страницы: «❓ Как здесь работать?».
  Подвал один на весь сайт (`app/layout.tsx`) — иконка появляется везде автоматически.
- Иконка ведёт на **отдельную страницу `/help`** (не попап): тексты растут, на отдельной
  странице удобно читать и листать, ею можно поделиться ссылкой.
- `/help` открывается **сразу на разделе той страницы, откуда кликнули** (`?из=<путь>`),
  но из оглавления можно открыть любой другой раздел.
- Формат раздела — **HTML со скриншотами** (не markdown): заголовок → скриншот экрана →
  «что на странице» → «что здесь можно сделать» → типовые сценарии. Голый markdown
  отклонён как «некрасивый» (решение Анатолия).
- Тексты и скриншоты живут **в репозитории**: разделы — компоненты в `content/help/`,
  скриншоты — `public/help/*.png`. Обновляются агентом в том же наборе правок, что и
  правка интерфейса (правило техписателя). Версионность — git-историей.

## Структура

- `app/help/page.tsx` — server component; `searchParams` в Next 16 — Promise (await).
  Параметр `из` (путь страницы) сопоставляется с разделом (точное совпадение или
  префикс); без параметра показывается оглавление-первый раздел. Параметр `раздел`
  открывает конкретный раздел по id.
- `content/help/` — один файл-компонент на раздел + реестр `sections.tsx`
  (id, заголовок, пути страниц, содержимое). Общий оформительский каркас —
  `Section`/`Shot` в `content/help/ui.tsx`.
- `components/HelpLink.tsx` — client-компонент: иконка в подвале, знает текущий путь
  (`usePathname`) и передаёт его в `?из=`. Подвал — в корневом layout, иконка видна
  на всех страницах, включая кабинет и админку.
- Скриншоты: `public/help/*.png`, делаются агентом через Playwright с dev-сервера
  (1280×800, светлая тема, обрезка до содержимого экрана). При правке UI скриншот
  раздела обновляется вместе с текстом.

## Безопасность

- `/help` — публичная страница, никакой авторизации; в текстах не раскрывать
  служебные детали (нет упоминаний ключей, SQL, служебных адресов).
- Разделы — React-компоненты (не dangerouslySetInnerHTML), пользовательского ввода
  нет — XSS-поверхности нет.

## Приёмочные критерии (согласованы 2026-09-04)

1. В подвале каждой страницы есть иконка «Как здесь работать?» — ведёт на `/help`.
2. `/help` открывается сразу на разделе страницы, откуда кликнули; из оглавления
   открываются другие разделы.
3. Тексты простым языком для не-программиста: что на странице, что делает каждая
   кнопка/вкладка, типовые сценарии.
4. Тексты и скриншоты в репо; после правок интерфейса обновляются в том же коммите.
5. Страница работает на мобильном (375×812) и в тёмной теме.
6. Разделы есть для всех страниц кабинета автора и админки (таблица выше).

## Проверки

- **E2E (агент, Playwright):** страница → иконка → свой раздел → листание других разделов.
- **Приёмочные:** по 6 критериям выше (агент + просмотр Анатолия).
- Контрактных/модульных нет (нет API и логики).

## Границы / открытые вопросы

- Скриншоты в репо (~2–3 МБ суммарно) — осознанный компромисс: версионируются вместе
  с текстами. При росте — переезжать в Storage и не хранить историю бинарников.
- Публичные страницы (главная, каталог, урок) без иконки-разделов: решено, что для
  посетителей они интуитивны; добавить при необходимости вторым этапом.
