# ИИ-агент RightWay

Автоматическое производство контента (бэклог №2 «Агентская часть ИИ-завода»):
по расписанию Windows запускается локальный CLI-агент (Claude Code, Codex CLI,
Gemini CLI — выбирается в `config.json`, поле `cli`) без интерфейса, берёт
следующую тему из плана автора (`/dashboard/ai/topics`), пишет текстовый урок
и публикует его через агентское API (`docs/specs/agent-api.md`) — на время,
заданное автором в «Управление с ИИ».

> **Для авторов платформы** канонический источник — файл-задание
> `/agent-setup.md` (кабинет → «Управление с ИИ» → «Инструкция для агента»):
> агент автора скачивает его и сам выполняет всю настройку. Эта папка —
> рабочая копия проекта; при изменении `prompt.md`/скриптов синхронизировать
> `public/agent-setup.md`.

## Состав

| Файл | Назначение |
|---|---|
| `prompt.md` | Инструкция агенту: выбор темы, написание урока, публикация, лог |
| `run-agent.ps1` | Обёртка: окружение + запуск CLI-агента + служебный лог |
| `run-agent.cmd` | Точка входа для планировщика Windows |
| `run-digest.ps1` | Ежедневная сводка обращений/жалоб (бэклог №11): API + md + тост |
| `run-digest.cmd` | Точка входа дайджеста для планировщика Windows |
| `config.example.json` | Шаблон конфига (скопировать в `config.json`) |
| `logs/` | Отчёты агента по запускам (в git не попадает) |
| `digest/` | Ежедневные сводки `<дата>.md` (в git не попадают) |

## Дайджест обращений (бэклог №11)

`run-digest.cmd` запускается планировщиком **при входе в Windows** (отдельная
задача, раз в день). Что делает:

1. Гвард «раз в день» (`logs/digest.log`).
2. Берёт админский ключ из `.env.local` (`AGENT_KEY`) и запрашивает у
   платформы `GET /api/agent/feedback?status=new` + `GET /api/agent/reports`.
3. Пишет сводку `digest/<дата>.md`: счётчики по статусам, новые обращения
   (тип, заголовок, дата), сводка жалоб «кто на кого», ссылки на админку.
4. Если есть новое — всплывающее уведомление Windows.

Расписание (одна команда от администратора):

```
schtasks /create /tn "RightWay Daily Digest" /sc onlogon /tr "\"<полный путь>\agent\run-digest.cmd\""
```

Базовый URL платформы: `https://coach-platform-pi.vercel.app` (переопределить
переменной окружения `DIGEST_BASE_URL`). Грабля PowerShell 5.1: скрипт должен
храниться в UTF-8 с BOM (иначе кириллица в строках ломается при разборе).

## Восстановление на новом ноутбуке (если старый вышел из строя)

Код и документация — в репозитории (`agent/`, `agent/README.md`), но часть
инфраструктуры живёт только в системе и секретах. Полный порядок с нуля:

1. **Клонировать репозиторий** (GitHub: Lavr0-25/coach-platform) в тот же
   путь `D:\Projects\coach-platform` — планировщики ниже прописаны на него.
2. **Установить CLI-агент** (по умолчанию Claude Code): `npm install -g
   @anthropic-ai/claude-code` и войти (`claude` → логин). Для codex/gemini —
   по полю `cli` в конфиге.
3. **Секрет агента-автора**: кабинет → «Управление с ИИ» → «API-ключи агента» →
   создать ключ → вставить в `agent/config.json` (по `config.example.json`,
   там же `base_url`). Если старый ключ не отозван — сначала отозвать его
   в кабинете (ключ утек вместе с ноутбуком = считается скомпрометирован).
4. **Секрет админа (для дайджеста)**: строка `AGENT_KEY` в `.env.local`
   (шаблон — `.env.example` при наличии; ключ создаётся в кабинете
   → «API-ключи агента» под админом, виден один раз). Ключ из Vercel
   (Environment Variables) — источник для восстановления. Старый — отозвать.
5. **Секреты Supabase/Vercel** (`NEXT_PUBLIC_*`, `SUPABASE_SERVICE_ROLE_KEY`):
   значения хранятся в Vercel (Environment Variables проекта
   coach-platform) — пересобрать `.env.local` оттуда.
6. **Зарегистрировать обе задачи планировщика** (PowerShell от администратора;
   триггер — вход в Windows, т.к. ночные запуски пропускались: ноут спал;
   гвард «раз в день» внутри скриптов не даёт гонять их при каждом входе):

```
schtasks /create /tn "RightWay AI Agent" /sc onlogon /tr "\"D:\Projects\coach-platform\agent\run-agent.cmd\""
schtasks /create /tn "RightWay Daily Digest" /sc onlogon /tr "\"D:\Projects\coach-platform\agent\run-digest.cmd\""
```

Проверка гвардов: повторный запуск за день пишет `skip` в
`logs/runs.log` / `logs/digest.log`, а не гоняет агента.

7. **Проверка**: запустить `run-agent.cmd` руками (должен появиться урок/лог)
   и `run-digest.cmd` руками (должен появиться `digest/<дата>.md` + тост).
8. **Кодировка-грабля**: файлы `agent/*.ps1` обязаны быть в UTF-8 **с BOM**
   — после редактирования проверять: первые байты `EF BB BF`.

## Настройка (для нового автора — копия этого набора)

1. **Ключ**: кабинет → «Управление с ИИ» → «API-ключи агента» → создать ключ
   (виден один раз).
2. **Конфиг**: скопировать `config.example.json` → `config.json`, вставить
   ключ. `base_url` — адрес платформы (у автора из РФ сейчас рабочий вариант —
   `https://coach-platform-pi.vercel.app`; домен myrightway.ru — когда откроется).
   ⚠️ `config.json` содержит секрет и в git не попадает (`.gitignore`).
3. **Проверка руками**: запустить `run-agent.cmd` — в кабинете должен
   появиться урок, в `logs/` — отчёт.
4. **Расписание** (одна команда от администратора; на этом ноутбуке с
   2026-09-08 триггер — вход в Windows, ночные запуски пропускались из-за сна):

```
schtasks /create /tn "RightWay AI Agent" /sc onlogon /tr "\"<полный путь>\agent\run-agent.cmd\""
```

## Границы (заложены в платформу, не в агента)

- Ворота качества на сервере: ≥2000 символов, стоп-слова, XSS-санитизация —
  агент не может их обойти.
- Не больше 3 автопубликаций в сутки на автора (429 при превышении).
- Агент видит только СВОИ темы и уроки (RLS), ключ отзывается мгновенно
  в кабинете.
