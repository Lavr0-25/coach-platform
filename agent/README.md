# ИИ-агент RightWay

Автоматическое производство контента (бэклог №2 «Агентская часть ИИ-завода»):
по расписанию Windows запускается Claude Code без интерфейса, берёт следующую
тему из плана автора (`/dashboard/ai/topics`), пишет текстовый урок и
публикует его через агентское API (`docs/specs/agent-api.md`) — на время,
заданное автором в «Управление с ИИ».

## Состав

| Файл | Назначение |
|---|---|
| `prompt.md` | Инструкция агенту: выбор темы, написание урока, публикация, лог |
| `run-agent.ps1` | Обёртка: окружение + запуск `claude -p` + служебный лог |
| `run-agent.cmd` | Точка входа для планировщика Windows |
| `config.example.json` | Шаблон конфига (скопировать в `config.json`) |
| `logs/` | Отчёты агента по запускам (в git не попадает) |

## Настройка (для нового автора — копия этого набора)

1. **Ключ**: кабинет → «Управление с ИИ» → «API-ключи агента» → создать ключ
   (виден один раз).
2. **Конфиг**: скопировать `config.example.json` → `config.json`, вставить
   ключ. `base_url` — адрес платформы (у автора из РФ сейчас рабочий вариант —
   `https://coach-platform-pi.vercel.app`; домен myrightway.ru — когда откроется).
   ⚠️ `config.json` содержит секрет и в git не попадает (`.gitignore`).
3. **Проверка руками**: запустить `run-agent.cmd` — в кабинете должен
   появиться урок, в `logs/` — отчёт.
4. **Расписание** (одна команда от администратора):

```
schtasks /create /tn "RightWay AI Agent" /sc daily /st 03:17 /tr "\"<полный путь>\agent\run-agent.cmd\""
```

## Границы (заложены в платформу, не в агента)

- Ворота качества на сервере: ≥2000 символов, стоп-слова, XSS-санитизация —
  агент не может их обойти.
- Не больше 3 автопубликаций в сутки на автора (429 при превышении).
- Агент видит только СВОИ темы и уроки (RLS), ключ отзывается мгновенно
  в кабинете.
