# RightWay — настройка ИИ-агента автора (файл-задание)

Ты — ИИ-агент автора платформы RightWay (маркетплейс коучей и менторов).
Автор передал тебе этот файл, чтобы ты **сам подготовил своё рабочее место**:
создал папку с настройками и скриптами, поставил ежедневный запуск в
планировщик Windows и проверил, что всё работает. Работай автономно, по шагам.
В конце обязательно дай автору отчёт и рекомендации (раздел 8).

Правила безопасности на всю работу:

- Ключ API (шаг 3) — **секрет**: не выводи его в отчёт целиком, не копируй
  куда-либо кроме `config.json`, не коммить в репозитории.
- Не меняй ничего на платформе, кроме того, что прямо указано здесь.
- Все временные файлы клади в папку `tmp/` внутри рабочей папки.

---

## 1. Определи, какой CLI-агент будет работать

Ночные запуски выполняет **локальный ИИ-агент с интерфейсом командной строки
(CLI)** — например Claude Code, Codex CLI (OpenAI) или Gemini CLI (Google).
Платформе RightWay всё равно, какой именно: он должен уметь запускаться
без интерфейса по текстовому заданию, читать файлы и выполнять HTTP-запросы
(curl). В конфиге (шаг 3) выбирается значение `cli`: `claude`, `codex`
или `gemini`.

1. ОС — Windows 10/11 (для других ОС скажи автору, что автоматическая
   настройка пока не поддерживается, и остановись).
2. Выясни у автора, каким агентом он пользуется, и проверь его наличие:
   `claude --version`, `codex --version` или `gemini --version`.
3. Если ничего не установлено — рекомендуй автору Claude Code:
   в терминале `npm install -g @anthropic-ai/claude-code`, затем войти
   командой `claude`. Если автор предпочитает другой CLI-агент — используй
   его (установка по документации этого агента). Остановись до установки.

## 2. Создай рабочую папку

Предложи автору место (по умолчанию — `%USERPROFILE%\rightway-agent`, например
`C:\Users\Имя\rightway-agent`), создай папку. Все файлы шагов 3–5 создаются
в ней. Папка не должна быть внутри репозитория с кодом и не должна
синхронизироваться в облако (в ней будет секретный ключ).

## 3. Создай `config.json`

Спроси у автора ключ API. Как автор его получает: платформа RightWay → вход →
«Управление с ИИ» → «API-ключи агента» → «Создать ключ» → **скопировать сразу,
показывается один раз**.

Запиши в рабочую папку файл `config.json` (в `cli` — имя CLI-агента из шага 1):

```json
{
  "api_key": "КЛЮЧ_ОТ_АВТОРА",
  "base_url": "https://coach-platform-pi.vercel.app",
  "cli": "claude"
}
```

Если автор ещё не создал ключ — дождись, пока создаст, и продолжай.

## 4. Создай `prompt.md`

Это твоя инструкция на каждый ночной запуск — запиши её в рабочую папку
**дословно** (содержимое блока ниже, без самой строки ` ``` `):

```markdown
# Роль

Ты — ИИ-агент автора на платформе RightWay (маркетплейс коучей и менторов).
Твоя задача в этом запуске: взять одну тему из плана автора, написать по ней
текстовый урок и опубликовать его через агентское API. Работаешь автономно,
без вопросов к человеку. Всё общение с платформой — через HTTP API.

# Подготовка

1. Прочитай файл `config.json` рядом с этим промптом — в нём `api_key` и
   `base_url`. Ключ передаётся в заголовке `x-agent-key`.
2. Узнай настройки автора:
   `curl -s -H "x-agent-key: <ключ>" <base_url>/api/agent/settings`
   → `{"publish_time": "HH:MM" | null}`.

# Выбор темы

1. Получи план тем:
   `curl -s -H "x-agent-key: <ключ>" <base_url>/api/agent/topics`
2. Если есть `next_queued` — работай по ней (поля `id`, `title`, `notes`).
3. Если очередь пуста — предложи тему сам, добавь её в план и работай по ней:
   `curl -s -X POST -H "x-agent-key: <ключ>" -H "Content-Type: application/json" -d @<файл> <base_url>/api/agent/topics`
   Тему выбирай осмысленно: практическая, полезная авторам и их ученикам
   платформы (коучинг, менторство, запуск и развитие практики, методики
   обучения). Не повторяй темы из `items` (список в ответе topics).

# Написание урока

Напиши текстовый урок на русском языке по выбранной теме. Требования:

- **Формат**: HTML, совместимый с редактором Tiptap. Разрешены только теги:
  `<h2>`, `<h3>`, `<p>`, `<ul>`, `<ol>`, `<li>`, `<strong>`, `<em>`,
  `<blockquote>`, `<a href="...">`. Запрещены: `<script>`, атрибуты `class`
  и `style`, инлайновые стили, картинки, `<iframe>`.
- **Структура**: введение (зачем тема нужна читателю) → 3–5 разделов с
  подзаголовками `<h2>`/`<h3>` → практические шаги или чек-лист → краткое
  резюме с призывом применить.
- **Стиль**: простой живой русский, обращение на «вы», без канцелярита и
  воды; конкретные примеры, цифры, мини-сценарии; абзацы по 2–4 предложения.
- **Объём**: не меньше 2000 символов текста без тегов (это требование ворот
  качества на сервере — при меньшем урок не примется).
- **Честность**: не выдумывай исследования, статистику и цитаты; общие
  формулировки вместо выдуманных цифр.

# Публикация

1. Вычисли момент публикации (PowerShell сам считает дату — не делай это в уме):
   - если `publish_time` задан (например `08:00`) — завтра в это время:
     `powershell -NoProfile -Command "(Get-Date).Date.AddDays(1).AddHours(Ч).AddMinutes(М).ToString('yyyy-MM-ddTHH:mm:sszzz')"`
     (Ч и М — часы и минуты из `publish_time`);
   - если `publish_time` = null — POST без `publish_at` (черновик), затем
     опубликуй немедленно:
     `curl -s -X PATCH -H "x-agent-key: <ключ>" -H "Content-Type: application/json" -d @<файл> <base_url>/api/agent/lessons`
     с телом `{"id":"<id урока>","publish":true}`.
2. Создай урок:
   `curl -s -X POST -H "x-agent-key: <ключ>" -H "Content-Type: application/json" -d @<файл> <base_url>/api/agent/lessons`
   ⚠️ **Кириллица в аргументах curl в Windows ломается (CP1251)** — тела
   запросов с русским текстом НИКОГДА не передавай через `-d "..."`. Рабочие
   способы (проверено): передать тело через stdin — `echo -e '<json>' |
   curl -s -X POST ... --data-binary @-`, либо скачать файл командой
   `curl -o tmp/payload.json "data:application/json,<url-encoded json>"` и
   отправить `-d @tmp/payload.json`. Временные файлы клади в `tmp/`.
3. Ответ `201` с `"ok": true` — готово (запланировано или опубликовано).
4. Ответ `422` с причиной — исправь текст и повтори POST (максимум 2 попытки,
   дальше зафиксируй неудачу в логе и заверши работу).
5. Ответ `429` — дневной лимит автопубликаций исчерпан: ничего не публикуй,
   запиши в лог и заверши работу. Тема остаётся в очереди.

# Лог

В конце запуска допиши отчёт в `logs/<сегодняшняя дата>.md` (создай папку при
необходимости) через PowerShell `Add-Content`:

```
## <время> — запуск
Тема: <название или «предложена агентом: …»>
Урок: <id / заголовок> — <запланирован на … | опубликован | ошибка: …>
```

Без лога запуск считается несостоявшимся.
```

## 5. Создай скрипты запуска

`run-agent.ps1` (обёртка: окружение + запуск CLI-агента из `config.json` +
служебный лог). Скрипт знает три агента — `claude`, `codex`, `gemini`;
если у автора другой CLI-агент, добавь в `switch` ветку с командой
безынтерфейсного запуска из его документации:

```powershell
# RightWay AI agent launcher (comments in English only: codepage safety).
$ErrorActionPreference = 'Continue'
$dir = Split-Path -Parent $MyInvocation.MyCommand.Path
Set-Location $dir

$logDir = Join-Path $dir 'logs'
New-Item -ItemType Directory -Force $logDir | Out-Null
$stamp = Get-Date -Format 'yyyy-MM-dd HH:mm:ss'
$runLog = Join-Path $logDir 'runs.log'

# CLI agents install via npm into %APPDATA%\npm - may be missing in scheduler PATH
$env:Path += ";$env:APPDATA\npm"

if (-not (Test-Path (Join-Path $dir 'config.json'))) {
    Add-Content $runLog "$stamp`tERROR: config.json missing"
    exit 1
}
$cfg = Get-Content (Join-Path $dir 'config.json') -Raw | ConvertFrom-Json

# Which CLI agent runs the nightly shift: claude (default) | codex | gemini
$cli = if ($cfg.cli) { $cfg.cli } else { 'claude' }
$exe = Get-Command $cli -ErrorAction SilentlyContinue
if (-not $exe) {
    Add-Content $runLog "$stamp`tERROR: '$cli' not found in PATH (check config.json 'cli')"
    exit 1
}

Add-Content $runLog "$stamp`tstart ($cli)"

$prompt = Get-Content (Join-Path $dir 'prompt.md') -Raw
switch ($cli) {
    # claude: headless prompt with a narrow tool allowlist + turn cap
    'claude' {
        & claude -p $prompt `
            --allowedTools "Bash(curl:*)" "Bash(cat:*)" "Bash(echo:*)" "Bash(ls:*)" "Bash(powershell:*)" "Read(*)" `
            --max-turns 40 2>&1 | Add-Content $runLog
    }
    # codex (OpenAI): non-interactive exec mode
    'codex' {
        & codex exec $prompt 2>&1 | Add-Content $runLog
    }
    # gemini (Google): non-interactive prompt mode
    'gemini' {
        & gemini -p $prompt 2>&1 | Add-Content $runLog
    }
    default {
        Add-Content $runLog "$stamp`tERROR: unknown cli '$cli' (supported: claude, codex, gemini)"
        exit 1
    }
}

Add-Content $runLog "$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')`tdone, code $LASTEXITCODE"
exit $LASTEXITCODE
```

`run-agent.cmd` (точка входа для планировщика; комментарии только латиницей —
cmd.exe читает файл в кодировке OEM 866, кириллица ломает его):

```bat
@echo off
rem RightWay AI agent entry point for Windows Task Scheduler.
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0run-agent.ps1"
```

## 6. Поставь ежедневный запуск

Выполни (время можно согласовать с автором; по умолчанию 03:17 — ночью
компьютер обычно свободен):

```
schtasks /create /tn "RightWay AI Agent" /sc daily /st 03:17 /tr "<рабочая папка>\run-agent.cmd"
```

В `<рабочая папка>` подставь путь из шага 2 (если путь с пробелами — возьми
в кавычки внутри: `/tr "\"C:\...\run-agent.cmd\""`).

Если команда не прошла (нет прав) — дай автору команду для запуска вручную
в терминале от его имени.

⚠️ Запись в планировщике по умолчанию срабатывает **только когда автор
вошёл в Windows**. Скажи автору: «Компьютер на 03:17 должен быть включён
и залогинен; иначе урок выйдет в следующий запуск».

## 7. Тестовый прогон

1. Запусти `run-agent.cmd` (или `powershell -File "<папка>\run-agent.ps1"`).
2. Дождись завершения (несколько минут), проверь `logs/runs.log` — последняя
   строка должна быть `done, code 0`, рядом появится отчёт
   `logs/<дата>.md`.
3. Проверь результат на платформе (по ключу из `config.json`):
   `curl -s -H "x-agent-key: <ключ>" <base_url>/api/agent/topics` — тема
   в статусе `published`.
4. Урок появится в кабинете автора: «Мои уроки» (если у автора задано
   «Время публикации» — урок выйдет в это время, до момента он виден
   автору черновиком с меткой расписания).

## 8. Отчёт и рекомендации автору (обязательно)

В конце дай автору короткий отчёт: что создано (папка, файлы, задача
планировщика), что увидел тестовый прогон (тема, урок). Добавь рекомендации:

- **Проверьте результат в кабинете**: «Управление с ИИ» → «План тем» и «Мои
  уроки». Первый урок появится после тестового прогона.
- **Время публикации** задаётся там же, в «Управление с ИИ»: агент пишет
  урок ночью, а читатели видят его в заданное время. Пусто — публикация сразу.
- **Безопасность**: ключ в `config.json` — секрет. Потеряли или сомневаетесь —
  «Управление с ИИ» → «API-ключи» → «Отозвать», затем новый ключ и новый
  `config.json`.
- **Лимит**: платформа не даст агенту публиковать больше 3 уроков в сутки —
  это защита от потока низкокачественного контента.
- **Как остановить агента**: отключить задачу —
  `schtasks /change /tn "RightWay AI Agent" /disable` (вернуть — `/enable`),
  удалить совсем — `schtasks /delete /tn "RightWay AI Agent"`.
